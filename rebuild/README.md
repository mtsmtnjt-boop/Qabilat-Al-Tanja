# قبيلة ال طنجة — إعادة بناء نظيفة

مشروع Godot 4.3 مستقل عن النسخة السابقة. هذا الفرع مخصص لإعادة بناء المشهد والواجهة والتحكم للموبايل.

## التشغيل
افتح هذا المجلد في Godot 4.3 وشغّل `scenes/main.tscn`.

## الحالة
هذه مرحلة تأسيسية قابلة للتشغيل وليست إصداراً نهائياً. الأصول الحالية مرسومة إجرائياً داخل Godot؛ يلزم استبدالها بنماذج إنتاجية مرخصة وإجراء اختبار بصري على Android قبل وصفها بأنها مطابقة للصورة المرجعية.
